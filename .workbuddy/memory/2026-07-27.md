## 部署成功 + 405 错误修复（16:07）
- 用户成功部署到 `https://ai-drama-master.pages.dev`
- 但访问注册 API 报 405：所有 `/api/*` 请求 fallback 到 index.html，Functions 没生效
- **根因**：Cloudflare Pages Functions 要求 `functions/` 目录必须放在 **Root directory** 下，而非 Build output directory
- **原配置**：Root directory 空 / Build output = `web` → Cloudflare 去仓库根找 functions/ 找不到
- **修复**：Root directory 改成 `web`，Build output 改空 → `web/functions/` 被识别为 Functions
- 修完 /api/test 返回 JSON，注册正常
