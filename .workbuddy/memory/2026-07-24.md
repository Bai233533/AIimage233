## 发现 CloudBase Web Apps 域名可用（17:30）

- **原因**：`webapps.tcloudbase.com` 是 CloudBase **Web 应用托管**（云托管）的域名，与静态托管的 `tcloudbaseapp.com` 和 HTTP 访问服务的 `service.tcloudbaseapp.com` 是不同服务，不受 418 策略限制
- **线上部署的版本**：用户上传的是 **CloudBase SDK 版本**（旧版 api.js），不是 Vercel fetch 版本

  - api.js 用 `cloudbase.init()` + `tcbApp.callFunction()` 调云函数
  - app.js 调用 `await API.init()`
- **API 调用路径**：SDK 通过中心网关 `tcb-api.tencentcloudapi.com` 调云函数，不走被封禁的环境域名
